3. Anima renderer contract
The LLM must return only one JSON object with arrays under these allowed keys:
- quality_meta_year_safety
- subject_count
- character
- series
- artist
- general
- negative

The renderer must:
- reject invalid structured output with DANBOORU_OUTPUT_INVALID;
- use fixed Profile components outside the LLM;
- order positive sections deterministically;
- lowercase ordinary tags;
- convert normal underscores to spaces;
- preserve score_N underscores;
- ensure artist tags use @;
- deduplicate fixed/generated duplicates;
- preserve Literal Content and Protected Terms exactly;
- return a separate negative string.

4. Variant fixed components
Base/Turbo:
Positive normally begins:
masterpiece, best quality, score_7, safe

Negative fixed list:
worst quality, low quality, score_1, score_2, score_3, artist name, blurry,
jpeg artifacts, chromatic aberration

Aesthetic:
- no fixed score_* in positive or negative
- masterpiece, best quality, safe may remain

If structured user content explicitly includes sensitive/nsfw/explicit, the
renderer must suppress conflicting default `safe` rather than contradict the
user.
